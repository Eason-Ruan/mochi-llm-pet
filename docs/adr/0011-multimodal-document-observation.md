# 0011 · 多模态 Observation 与当前文档

本决策修订 [0009 的桌面实时流水线](0009-observation-v2.md)。[Notion 设计与契约](https://app.notion.com/p/421eb246ea0681f4a3a4ffeaa1c19b07)

## 用户能问什么

用户在文档 A 工作，切到文档 B，然后点开 Mochi。回答“刚才在哪份文档”时，System 2 应能指出最后一次确认 B 的时间。仅当观测能把变化归因于 A 的编辑区时，才能进一步描述 A 的内容发生变化。前台窗口、键鼠活跃、文档已有未保存修改等单独信号都无法证明用户刚刚编辑、保存或完成了任务。

VS Code 的活动标题明确暴露未保存标记时，若同一已授权文档在连续采样中从无标记转为有标记，记录 `unsaved_changes_appeared` 及观测时间。首次看到就有标记、模板隐藏标记、切窗或观测中断时不作这一推断。macOS 默认的 VS Code 标题省略这个标记，仍可记录活动文件名。[VS Code 窗口标题定义](https://github.com/microsoft/vscode/blob/main/src/vs/workbench/browser/parts/titlebar/windowTitle.ts)

## 采样与读取

- 本地持续采样前台、锁屏和输入时效，每 30 秒更新活动判断。窗口稳定、画面出现有意义的新变化且预算允许时，Observation 独立的 DSH 循环发起一次多模态调用，读取画面和获准发送的结构化信号。固定第二次文本调用保留给旧版对照。
- 30 秒的上传冷却按宿主为图像提交模型请求的时间计量，跨采集器重启保留。网络延迟会影响供应商实际收到请求的间隔。
- 本地分别记录当前系统事实、最近一次看清的外部活动及其真实采集时间、可打扰状态。实时 Observation 的 `valid_until` 为 `null`。采集器持续确认同一场景时，System 2 可以在每 60 秒的后台评估中使用该场景最新结果。画面保留原采集时间，场景变化或采集失联时按实际状态复核。切到 Mochi 后可以引用历史活动。
- 同应用切换文档或场景时，最近一小时的历史按具体活动分段。无法确认的间隔单独表示。摘要、时间和采集健康状态各自传递。
- 从获准的应用窗口或文档网站的活动标题读取文档名。视觉回退只用原本就允许发送的画面。省略路径、URL、正文、侧栏和最近打开列表。用户分别选择允许本机记住的来源，以及允许云端 System 2 收到名称的来源。默认两项为空，云共享还需要相应的本机及云端活动共享授权。
- 首批支持原生 Word、Excel、VS Code，以及 macOS 支持的 Chromium 浏览器内、明确允许域名下的文档页面。云视觉的已有截图授权继续支持单图识别。用户可在同一接收方升级授权，附带最近系统信号，也可单独撤回这些信号。
- 逐字段验证模型结果，有效的场景要素可以独立保留。完整的自由文本事实校验另见原 ADR 的后续设计。
- 实时采集器沿用原来的视觉供应商、模型、凭据和截图授权。暂停或替换采集器时取消在途视觉推理。DSH 或视觉模型失败时记录采集健康 `model_failed`，继续本地活动判断。
- 视觉回合使用独立的请求预算，并在结束后复核采集时固定的接收方及授权。入库和实时发布与授权变更串行。场景已改变的结果可归入历史。接收方、授权或采集策略已变更时，已完成的结果只以脱敏状态入库。

## 验证边界

公开录屏可验证画面理解、重复画面的调用次数和场景覆盖。只有带系统信号的可控回放才能验证打开桌宠、输入缺失、锁屏和授权撤销等行为。模拟调用不计入实测云费用，真实云调用使用服务返回的用量。

用新目录接收可复查的结果。例如在仓库根目录运行以下命令，三种模式共用一条合成系统活动轨迹。

```sh
python -m scripts.check_observation_multimodal --suite desktop --output /tmp/mochi-document-replay
```

生产桌宠和手动 `python -m deskpet.observation_v2 live` 使用独立的 Observation DSH 循环。旧版双模型通过本地录屏 `replay` 运行，`replay --multimodal` 使用自适应采样。回放图像由本地 Ollama 处理。双模型回放带 `--cloud-settings` 时，文本阶段遵循所配置的状态接收方。合成系统轨迹使用固定响应，`cloud verify` 使用合成输入测试接收方能力，生产 DSH 接线另有端到端测试。

三组原片的采样时刻、场景覆盖、实际 token 用量和已知缺口见[多模态验收报告](../evaluation/observation-multimodal.md)。
